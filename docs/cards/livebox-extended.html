Livebox Extended

Home Assistant integration for the Orange Livebox router and the Orange Wi-Fi 6 / Wi-Fi 7 repeaters, talking to them locally (sysbus API on the box and the Wi-Fi 6 repeater, prplOS REST API on the Wi-Fi 7 repeater).

It started as a fork of cyr-ius/hass-livebox-component and adds the parts that integration does not cover: repeater telemetry, Wi-Fi security control and throughput figures that match what is really on the air. The repeater tables and conventions follow LiveboxMonitor by Pierre Dor. See Credits.

Tested on a Livebox 6 with an Orange Répéteur Wi-Fi 6 and an Orange Répéteur Wi-Fi 7.

Not affiliated with, endorsed by or supported by Orange. "Livebox" and the Orange logo are trademarks of Orange.

Features

Box

  • WAN status (public IPv4/IPv6 as attributes), uptime, fibre (GPON) optical levels, down/up rates.
  • Per-interface rates (Ethernet ports, Wi-Fi bands) and lifetime totals.
  • Real per-band Wi-Fi throughput, summed from the per-station counters (the box's own Wi-Fi interface counters miss hardware-forwarded traffic such as IPTV).
  • Wi-Fi and guest Wi-Fi switches, WPS switch, Wi-Fi security mode select per band (WPA2 / WPA2-WPA3 / WPA3), remote access switch.

    ⚠️ Older or IoT devices may fail to connect in WPA2-WPA3 or WPA3, even some that claim WPA3 support. Moving a home network to WPA2-WPA3 broke enough devices here to be reverted. Change it when you can check your devices afterwards.

  • Buttons: restart the box, ring the phone, clear missed calls.
  • Missed calls sensor and call log calendar.
  • DHCP leases, UPnP port forwards.

Connected devices

  • A device_tracker per device (Wi-Fi and/or LAN, configurable).
  • A switch per device to block or allow its Internet access.
  • Diagnostic sensors per device: IP address, MAC address, Livebox name, access point ("Livebox Wifi 5GHz", "Répéteur WiFi 7 2.4GHz", "Livebox ETH2", ...), Wi-Fi signal and band.

Repeaters (each one gets its own Home Assistant device, linked to the box)

  • Detected automatically from the box device list, no IP to type in.
  • Per-interface rates and totals (LAN, Ethernet, Wi-Fi bands, backhaul), connected stations per band with their signal.
  • Wi-Fi 6 repeater: read over sysbus. Wi-Fi 7 repeater: read over its prplOS REST API.
  • Best-effort: a repeater that does not answer never blocks the box update, its sensors simply are not created or become unavailable.

Manual

Copy custom_components/livebox_pro into the custom_components folder of your Home Assistant configuration, then restart.

The integration domain is livebox_pro, so it can run alongside the cyr-ius integration (livebox) while you compare them. Running both polls the box twice as often.

Configuration

Setup asks for the box address (default 192.168.1.1), the admin username (admin) and the admin password, the one printed on the box label unless you changed it. The repeaters use the same admin password as the box.

Options (Settings > Devices & services > Livebox Extended > Configure):

Option Default Meaning
Wi-Fi tracking on Create a device_tracker for Wi-Fi devices
LAN tracking off Create a device_tracker for wired devices
Tracking timeout 300 s How long a device stays home after it was last seen
Device tracker mode Active only All also creates trackers for devices currently offline
Repeater IPs empty Leave empty for auto-detection. Otherwise comma-separated IPs; the type of each one (Wi-Fi 6 or 7) is probed once

How it works

  • Fast data (rates, WAN status) is refreshed every 30 s; heavy data (devices, DHCP, forwards, calls, Wi-Fi settings, repeater discovery) every 2 minutes. A new device therefore shows up within about 2 minutes.
  • Repeaters are found by asking the box for devices whose type matches repeteur* (repeteurwifi6, repeteurwifi7). Their IP address is used even when the box marks them Active=False: the box often keeps a repeater listed as the Wi-Fi client it was during pairing.
  • Rates are in bytes per second (shown as kB/s or MB/s), as in LiveboxMonitor. Repeater Rx/Tx are oriented from the user's point of view: Rx is what goes down to the clients.

Limitations

  • One repeater per type (one Wi-Fi 6, one Wi-Fi 7). A second repeater of the same type is ignored.
  • On the Wi-Fi 7 repeater, the 5 GHz rate comes from its bridge port: that radio's per-station counters miss the data traffic. The 2.4 GHz radio works the other way round and keeps the per-station sum.
  • Only tested on a Livebox 6. Other models speaking sysbus (Livebox 4, 5, 7) are expected to work for the box part but are untested.
