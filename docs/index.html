NEON CARDSfor Home Assistant

Cyberpunk / Neo Tokyo neon cards for Home Assistant: weather with a WebGL sky, climate, battery, thermometers, gauges, nixie clock, CRT terminal, markdown and entities. Each card installs on its own via HACS.

Collection on GitHub

Dashboard cards

Weather Neon Card

Neon weather card for Home Assistant with a live WebGL sky: rain on the glass, fog, frost, snow, lightning and a real moon. HACS-ready.

Neon Climate Card

Cyberpunk climate card for Home Assistant — airflow rendered by a real WebGL fluid solver

Storey Battery Card

Home battery card for Home Assistant: a 3D Storey battery stack with live electric arcs (WebGL), dot-matrix panels, neon theme. HACS.

Neon Dual Thermo Card

Dual thermometer card for Home Assistant: two neon thermometers with refracting glass, liquid, plasma core and bubbles (WebGL), 24 h history graph. HACS.

Neon Dual Gauge Card

Two concentric neon LED gauges for Home Assistant, with a WebGL plasma core. HACS-installable.

Nixie Clock Card

Nixie tube clock card for Home Assistant: six IN-14 tubes with glowing gas, cyan underlights and acrylic base (WebGL), plus a CSS variant. HACS.

Linux Terminal Card

Sci-fi CRT terminal card for Home Assistant: CPU, GPU, RAM, temperature, battery, network and updates of a Linux PC, rendered by a WebGL shader (CSS fallback), with a ghost cat.

Neon Markdown Card

Neon Markdown card for Home Assistant: client-side Jinja templates, full HTML/SVG/CSS body, neon header. HACS-ready.

Neon Entities Card

Neon entities card for Home Assistant: per-domain neon controls, alert rows, momentary switches, glowing header. HACS ready.

Neon Header Card

Neon title and subtitle header for Home Assistant: glow, gradient text, flicker, scanline, slice glitch. HACS ready.

Neon Theme Snippets

Small CSS snippets for Home Assistant themes (card-mod): sidebar code rain and more
